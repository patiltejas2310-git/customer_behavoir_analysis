Customer Shopping Behavior – Data Analytics Project
🔎 Overview

This project analyzes customer shopping behavior using transactional purchase data. It focuses on uncovering insights into customer segments, spending patterns, product preferences, discount impact, and subscription behavior to support data-driven business decisions.

🗂️ Dataset

Transactional dataset containing ~3,900 purchase records

Multiple product categories

Includes customer demographics, purchase amount, discounts, and subscription details

🛠️ Tools & Technologies

Python – Data cleaning & Exploratory Data Analysis (EDA)

SQL (PostgreSQL / MySQL / SQL Server) – Business query analysis

Power BI – Interactive dashboard development

PowerPoint – Final presentation/report creation
